The newsletter submission deliberately stops at the inbox confirmation step;
the suite also follows its confirmation capability and verifies an ordinary
response is created only then. Appointment and order templates explicitly
collect requests, without promising a reservation or charging a card.

* Regression evidence

All 88 forms tests pass. Every template imports, renders through the shared
accessibility checker and accepts a valid answer. Tests cover JSON and YAML
round trips with pages, rules, repeat groups and translations; reference
bindings and organization boundaries; exact monetary prices; and refusal of
aliases, multiple YAML documents, unknown fields/kinds, forged identities,
wrong value types and missing groups. Refused imports leave no form behind.

The round-trip test initially failed because a shallow JSON-node copy shared
the original object and removed the repeat-group binding. Owning the outer
mapping before converting portable controls fixed that failure. Decimal
minor-unit amounts are refused rather than silently rounded.
