* Interpretation

The source arithmetic and exact workflow are specified independently in
[[file:../accounting-acceptance.org][Accounting acceptance]]. There is no compensating balance adjustment: the
five-dollar correction only reclassifies expenses. Restore compares every
archived field after explicit identity/reference/key remapping, including
historical timestamps, versions, bank matches and close evidence. Restart
checks include the restored record set, not only its row count.

The reviewer and preparer are different synthetic authenticated OWNER
accounts in ordinary standalone mode. This demonstrates separation at the
close-signature boundary, not hosted role administration or independent
accountant authorization. The run uses SQLite; service-level PostgreSQL
checks are separate evidence. It does not establish M2 deployment readiness,
customer migration acceptance, production operations, or full-tenant recovery.
