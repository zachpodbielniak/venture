#+title: Conditional forms demonstration

* Built server

A disposable SQLite instance on loopback, with AI, plugins and automation
disabled, served a three-page form through its ordinary public HTTP routes.
Chromium exercised both the script-free hosted page and an embedded loader
on a separate HTTP origin. Synthetic questions and answers were used.

The form showed and required an explanation for “other”, jumped over the
personal page for “business”, and ended early for “other”. The crafted POST
sent a hidden explanation anyway; the persisted responses did not contain it.
A second loader form combined a condition from an earlier page with one from
the current page. No earlier answer was copied into a hidden input.

* Regression coverage

=/forms/rules= checks discarded hidden and skipped answers, conditional
requirements, required branches, a combined condition across pages, early
completion, Back after a jump, published rule pinning, schema exposure, dangling
and cyclic references, unsupported operators, and “Not shown” report counts.
=/forms/rule-vocabulary= checks case-sensitive equality, multiple-choice
membership, negation, contains, any-of, numeric bounds, non-finite numbers and
empty answers. The full forms suite contains 48 tests.

The existing markup checker and axe-core runs include every answer kind and
intermediate multi-page state. The browser axe check above additionally examines
a conditionally revealed required question. This is not a human screen-reader
session or cross-browser certification.
