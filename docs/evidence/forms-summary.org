* Regression evidence

All nine AI summary tests and 83 forms tests pass. Coverage includes empty
input, current and deleted sensitive questions, organization/version/date
scope, malformed output, response and byte bounds, disabled modules,
distinct citation counts, exact quotation checks and proposal-only actions.
The bounded provider input keeps submitted instructions inside the explicitly
untrusted records section. The summary is a proposal for a person to review;
no result is automatically saved and no model command is executed.
