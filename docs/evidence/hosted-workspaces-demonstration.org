#+title: Hosted workspace application demonstration

* Built artifact and scope

This is a synthetic application demonstration, separate from the operator's
container isolation, encrypted restore and neighbor-availability drill. It used
the DEBUG =venture= binary, a fresh private SQLite database, numeric loopback
origin, Chromium and no external provider. Passwords and capabilities were
submitted privately and are absent from this transcript. The recording shows
before/after administrator pages: global EDITOR, visible control rows and the
retained colleague as tenant member. Acceptance forms run in a separate browser
context and are established by the verbatim scripted transcript, not the clip.

Run =python docs/evidence/hosted-workspaces-demonstration.py= from an environment
with Playwright and Chromium installed, after =make DEBUG=1=. The script derives
the repository path, creates its own private database/state, starts and stops the
built server, and retains the private evidence directory for inspection.
It never connects to the ambient database.

* Automated boundaries

=test-tenant= covers immutable identity, explicit classification, safe invitations,
last-admin protection, scoped support and revocation, nested maintenance isolation,
lifecycle actions, HTTP authority/completion checks, restored mandatory MFA
reenrollment, transactional credential quarantine, retained ordinary-member
recovery, and an absent optional OIDC table. The same eleven cases pass on SQLite
and a disposable PostgreSQL schema. Retained OIDC identities are revoked even
when the module is disabled; schema absence is checked separately.

The related auth, organization access, MFA, OIDC, actions, modules, migrations,
private connectors and CLI transport suites passed. GIR generation passed without
warnings. This evidence does not replace an independent security review, deployment
egress isolation or full integrated-head qualification.

The OIDC suite's two live-Keycloak opt-in cases were not run for this lane;
its twenty hermetic cases passed. PostgreSQL migration coverage ran separately
with the dedicated disposable fixture. No external identity/provider request was
made by hosted quarantine or the application demonstration.

unknown access verb and for Secure cookies behind an HTTPS public origin with
HTTP backend transport. The eleven-case SQLite gate and fresh built-artifact
demonstration passed again after those repairs. The docs checker rendered all
92 pages after completing the index links.
