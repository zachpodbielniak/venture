#+title: Accounting parity — the gap branch

This branch, =feat/accounting-parity=, is where the work for the Zoho Books /
QuickBooks gap tracker (issue #70) lands. One pull request stays open against
=master= while the gaps close; each gap is its own issue, its own commits, and
its own tests, merged into this branch rather than straight to =master=.

* How work lands here

- Take one issue from #70. Branch from =feat/accounting-parity=, not =master=.
- Tests first, then the change, then this page: move the issue below from
  "Open" to "Landed" with the commit that closes it.
- Rebase onto =feat/accounting-parity= and merge there; the umbrella PR
  carries the running list for review.
- Nothing here re-implements what =master= already has; the tracker's "What
  already exists" list is the boundary.
