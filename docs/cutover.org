#+title: Accounting cutover
#+description: Guided Zoho Books and QuickBooks opening-balance migration

* Cutover

The =cutover= module requires =ledger=. =VentureCutoverService= owns preview, import, reconcile, activate
and rollback. Generic writes do not create opening journals.

A mapped JSON payload names the source (=zoho_books= or =quickbooks=), an
explicit cutoff, chart mapping, customers, vendors, items, open AR/AP, credits,
bank balances and assets. Unsupported source fields are listed on the retained
reconciliation report. Each source ID is stored on =accounting_cutover_row= so
reimport is idempotent.

Open AR is imported as issued invoices (tax split at issuance) rather than as a
second opening journal, so operational documents and opening cash are not
double-posted. Bank opening cash is one balanced journal against equity.
Activation is refused until reconcile has accepted trial balance, issued
opening AR and bank opening cash. Rollback is allowed only before activation:
it reverses the opening cash journals and voids the imported invoices. Generic
writes cannot stamp a reconciled state. The Cutover nav item opens the batch
record; preview, import, reconcile, activate and rollback are actions on that
page.

#+begin_src sh
venturectl action accounting_cutover import 1
#+end_src
