** The shape of the thing in one page

Everything derives from GObject properties. A record type is a field table; from that VENTURE builds the database table, the REST resource, the JSON and YAML serialisation, the web form, the AI tool schema, the audit diff and the CLI subcommands. Adding a field is a line; adding a record type is a registration.

Money is never a double. =VentureMoney= is an exact integer count of minor units plus a currency and its exponent. Every operation checks for overflow, rounding is half to even, splitting preserves the total exactly, and arithmetic across currencies is refused rather than guessed.

Nothing is deleted. Deletion stamps a time; the row stays, so a report over a past period still reconstructs and an accidental deletion is recoverable.

The AI reads freely and cannot write unsupervised. A tool call that would change a record stages a diff for approval instead; only approval applies it, and the applied write is audited with the prompt that caused it. Any REST write can do the same with =?stage=1=, so an outside agent proposes into the same queue and a person answers both from one page.

Two binaries, both statically linked against every vendored dependency: =venture= is the server, =venturectl= is the client. Either builds alone.
