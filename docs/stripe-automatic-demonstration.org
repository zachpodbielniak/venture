#+title: Automatic collection — built-artifact demonstration
#+description: Reproducible operator transcripts for issue 125

These verbatim transcripts run the DEBUG-linked Venture test artifact. The
operator action uses a real loopback Venture HTTP server and the built
=venturectl=; provider responses come from a stateful offline StripeTransport.
The fixtures use synthetic organizations, customers and money. They demonstrate
application behavior and retained accounting evidence, not live-bank timing or
physical recovery performance. The pinned stripe-glib revision is
=fbc66e52ddaa8e6294aaa5c48d36bf206c286105=.

Reproduce with =make DEBUG=1=, =make DEBUG=1 plugins= and
=make DEBUG=1 build/debug/tests/test-stripe=, then run the commands below.
The full Stripe suite also covers the existing hosted ACH, return, closed-period,
separation-of-duties, account-isolation and currency cases. PostgreSQL checks use
schema-isolated disposable databases with fsync enabled.
